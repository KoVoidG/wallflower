# UX Rules

The dashboard preview should always showcase the real product.

Avoid stock illustrations.

Navigation should remain minimal.

Primary CTA should always be visible above the fold.

Authentication pages should minimize distractions while reinforcing trust through product previews.

Marketing content should focus on solving business problems rather than listing technical features.

The website should guide users naturally from discovering Wallflower to creating an account and completing onboarding.
